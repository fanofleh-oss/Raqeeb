# رقيب | RAQEEB

مساحة عمل عربية ثنائية اللغة للتحقق من الادعاءات، تنظيم الأدلة، وفهم التضليل الإعلامي بطريقة قابلة للمراجعة.

## ما الذي يقدمه؟

- سجل ادعاءات مستقل مع حكم تحريري ودرجة ثقة وتعليل واضح.
- ربط كل ادعاء بالمصادر المؤيدة أو المعارضة.
- توثيق الناشر والكاتب والتاريخ والأصل المشترك والنسخة المؤرشفة.
- مراجعة تحليلية من 45 سؤالًا ضمن 9 محاور.
- تقارير مؤرخة قابلة للطباعة والتصدير.
- واجهة عربية/إنجليزية متجاوبة مع الهاتف.
- تحليل مفصّل عبر Google Gemini مع مخرجات JSON منظّمة.
- مطابقة الاقتباسات مع النصوص المحفوظة وكشف الأصول المكررة.
- تخزين محلي ونسخ احتياطي JSON.

## فلسفة المصداقية

رقيب لا يعرض «نسبة حقيقة» آلية. النتيجة التحريرية مرتبطة بأدلة محددة، وتوضح مستوى الثقة والفجوات والخطوة التالية. تكرار الخبر لا يعد تأكيدًا مستقلًا إذا كانت النسخ تعود إلى أصل واحد.

## التكاملات

صُممت الواجهة لربط خدمات البحث عن تحقيقات سابقة، واستخراج المقالات، والأرشفة، وC2PA، وفحص الصور والفيديو، والترجمة، ومزودي الذكاء الاصطناعي، أو أي REST API.

كل مستخدم يضيف مفتاح Gemini الخاص به من صفحة الإعدادات. يبقى المفتاح في `sessionStorage` داخل علامة التبويب، ولا يدخل بيانات القضايا أو النسخ الاحتياطية أو GitHub. عند بدء التحليل فقط يمر المفتاح والقضية الحالية عبر وظيفة Vercel إلى Google Gemini، ولا تخزّن الوظيفة المفتاح.

## استعمال Gemini

1. افتح **الإعدادات والنسخ**.
2. ألصق مفتاح Google AI Studio الخاص بك.
3. اختر النموذج، والافتراضي هو:

```text
gemini-2.5-flash
```

4. اضغط **استخدام هذا المفتاح** ثم افتح قضية وأضف مصادرها وابدأ التحليل.

لا تضع المفتاح في GitHub أو ترسله لشخص آخر. حذف المفتاح من الجلسة أو إغلاق التبويب ينهي استعماله في الموقع.

## تشغيل محلي

```bash
python3 -m http.server 4173 -d public
```

ثم افتح `http://localhost:4173`.

## حالة المشروع

التحليل الآلي يعمل بمفتاح كل مستخدم من داخل الرابط. جلب المقال تلقائيًا من الرابط ما زال اختيارياً؛ يمكن لصق النص أو استيراد ملف نصي الآن.
