# رقيب | RAQEEB

مساحة عمل عربية ثنائية اللغة للتحقق من الادعاءات، تنظيم الأدلة، وفهم التضليل الإعلامي بطريقة قابلة للمراجعة.

## ما الذي يقدمه؟

- سجل ادعاءات مستقل مع حكم تحريري ودرجة ثقة وتعليل واضح.
- ربط كل ادعاء بالمصادر المؤيدة أو المعارضة.
- توثيق الناشر والكاتب والتاريخ والأصل المشترك والنسخة المؤرشفة.
- مراجعة تحليلية من 45 سؤالًا ضمن 9 محاور.
- تقارير مؤرخة قابلة للتصدير كملفات Word (`.docx`).
- واجهة عربية/إنجليزية متجاوبة مع الهاتف.
- تحليل مفصّل عبر Gemini وOpenAI وHugging Face وGroq، أو أي واجهة متوافقة مع OpenAI.
- اختبار المفتاح وجلب قائمة النماذج المتاحة تلقائيًا من داخل الإعدادات.
- مطابقة الاقتباسات مع النصوص المحفوظة وكشف الأصول المكررة.
- تخزين محلي ونسخ احتياطي JSON.

## فلسفة المصداقية

رقيب لا يعرض «نسبة حقيقة» آلية. النتيجة التحريرية مرتبطة بأدلة محددة، وتوضح مستوى الثقة والفجوات والخطوة التالية. تكرار الخبر لا يعد تأكيدًا مستقلًا إذا كانت النسخ تعود إلى أصل واحد.

## التكاملات

صُممت الواجهة لربط خدمات البحث عن تحقيقات سابقة، واستخراج المقالات، والأرشفة، وC2PA، وفحص الصور والفيديو، والترجمة، ومزودي الذكاء الاصطناعي، أو أي REST API.

كل مستخدم يضيف مفتاح المزود الخاص به من صفحة الإعدادات. يبقى المفتاح في `sessionStorage` داخل علامة التبويب، ولا يدخل بيانات القضايا أو النسخ الاحتياطية أو GitHub أو ملفات Word. عند بدء التحليل فقط يمر المفتاح والقضية الحالية عبر وظيفة Vercel إلى المزود المختار، ولا تخزّن الوظيفة المفتاح.

## استعمال الذكاء الاصطناعي

1. افتح **الإعدادات والنسخ**.
2. اختر المزود: Gemini أو OpenAI أو Hugging Face أو Groq أو مزودًا خاصًا متوافقًا مع OpenAI.
3. ألصق مفتاح API الخاص بك.
4. اضغط **اختبار المفتاح وجلب النماذج**.
5. اختر نموذجًا ثم اضغط **حفظ واستخدام**.
6. افتح قضية، أضف المقالات أو روابطها، ثم ابدأ التحليل المجمع أو تحليل كل مقال على حدة.

لا تضع المفتاح في GitHub أو ترسله لشخص آخر. حذف المفتاح من الجلسة أو إغلاق التبويب ينهي استعماله في الموقع.

## تشغيل محلي

```bash
python3 -m http.server 4173 -d public
```

ثم افتح `http://localhost:4173`.

## حالة المشروع

التحليل الآلي يعمل بمفتاح كل مستخدم من داخل الرابط. يمكن جلب المقال تلقائيًا من رابطه، أو لصق النص، أو استيراد ملف نصي. التصدير النهائي ينتج ملف Word حقيقيًا.
